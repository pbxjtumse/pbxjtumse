## 🧱 技术建设路线

目前正在尝试使用不同编程语言重新思考相同的工程问题，重点不是简单翻译代码，而是理解不同运行时和编程模型下的架构实现方式。

```text
Java 技术底座
├── Foundation
├── Retry
├── Cache
├── Messaging
├── Idempotency
├── Transaction
├── Distributed Lock
└── Observability

Python 技术底座
├── Foundation
├── Async Runtime
├── Retry
├── Messaging
├── Idempotency
├── Transaction
├── Observability
└── AI Runtime
    ├── Model
    ├── Prompt
    ├── Tool
    ├── Workflow
    ├── Agent
    ├── Memory
    ├── RAG
    └── Evaluation

TypeScript / NestJS 技术底座
├── Foundation
├── Web / API
├── Validation
├── Persistence
├── Transaction
├── Messaging
├── Idempotency
├── Cache
├── Security
└── Observability
```

目标不是把同一套 Java 代码分别翻译成 Python 和 TypeScript，而是深入理解：

```text
Java Thread / CompletableFuture

        VS

Python asyncio / async-await

        VS

Node.js Event Loop / Promise
```

以及不同运行时下事务、消息、幂等、上下文传播、可观测性和高并发处理方式的差异。
